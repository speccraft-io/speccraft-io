<p class="home-lead">SpecCraft is about formal methods in TypeScript projects. Below are some situations we run into from time to time. See if any of them look familiar, and learn how formal methods (and other modern tools) can help.</p>

## Connect on first use

Connect to the database on first use, then reuse the connection. Two requests at startup both see no connection yet,
and both connect.

<CodeFix before={tlaBefore} after={tlaAfter} title="src/lazy-connect.ts" />

See how [TLA+](/formal-method-tools/tla-plus) finds it.

## Search as you type

A search-as-you-type box sends a request on every keystroke and shows whatever comes back. Type "rea", then "react",
and two requests are waiting for a reply. If the one for "rea" is slower, it arrives last and replaces the results:
the box says "react", the list shows results for "rea".

<CodeFix before={quintBefore} after={quintAfter} title="src/search.ts" />

See how [Quint](/formal-method-tools/quint) finds it.

## Binary search over sorted ids

Finding an id in a sorted list. Tests for a found id and a missing id both pass, but `indexOfId([10, 20, 30], 10)`
returns `-1`: when the search narrows down to one last element, the loop stops before looking at it.

<CodeFix before={dafnyBefore} after={dafnyAfter} title="src/ids.ts" />

See how [Dafny](/formal-method-tools/dafny) finds it.

## A percentage discount

A price with a percentage discount and a cap. Nothing stops `percent` from being over 100, and the discount is then
bigger than the price, unless the cap happens to catch it.

<CodeFix before={leanBefore} after={leanAfter} title="src/pricing.ts" />

See how [Lean](/formal-method-tools/lean) finds it.
