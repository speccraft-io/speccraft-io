SpecCraft is a tool, framework and method for spec-driven development.

You write the requirements. AI writes the spec, then the tests, then the code. A gate checks each step against the
one before. Specs live next to the code and go through the same pull requests.

**Pre-release.** The editor (edits specs in a GitHub repo, from a laptop or a phone) and the Claude Code plugin
(the method, the agents, the gate) are coming soon, both open source.
