SpecCraft is a tool, framework and method for spec-driven development with AI:

    human requirements -> AI spec -> AI tests -> AI code

You write high-level requirements and pain points. AI writes the spec and keeps it complete and consistent, with
every open question and the call made to close it written down. Tests are generated from the spec. Code is written
only to make a failing test pass. Specs live next to the code and go through the same pull requests.

- **The editor** at [app.speccraft.io](https://app.speccraft.io) reads and edits requirements and specs straight from
  a GitHub repo, from a laptop or a phone.
- **The Claude Code plugin** holds the method, the spec-writer and spec-auditor agents, and the gate that checks
  requirements, specs, test cases and tests against each other.

## Formal methods

Specs in SpecCraft lean on formal methods where they can. The
