<p class="home-lead">Below are some bugs TypeScript developers run into from time to time. See if any of them look familiar, and learn how formal methods (and other modern tools) can help.</p>

## Search as you type

A search-as-you-type box sends a request on every keystroke and shows whatever comes back. Type "rea", then "react",
and two requests are in flight. If the one for "rea" is slower, it arrives last and replaces the results: the box says
"react", the list shows results for "rea".

<CodeFix before={quintBefore} after={quintAfter} title="src/search.ts" />

See how this is diagnosed with [Quint](/tools/quint).

## One shared call per key (single-flight)

Callers that ask for the same key at once share one call. If that call fails, its rejected promise stays in the map,
and every later caller gets the old error without trying again.

<CodeFix before={tlaBefore} after={tlaAfter} title="src/single-flight.ts" />

See how this is diagnosed with [TLA+](/tools/tla-plus).

## A percentage discount

A price with a percentage discount and a cap. Nothing stops `percent` from being over 100, and the discount is then
bigger than the price, unless the cap happens to catch it.

<CodeFix before={leanBefore} after={leanAfter} title="src/pricing.ts" />

See how this is diagnosed with [Lean](/tools/lean).

## Binary search over sorted ids

Finding an id in a sorted list. Tests for a found id and a missing id both pass, but `indexOfId([10, 20, 30], 10)`
returns `-1`: when the search narrows down to one last element, the loop stops before looking at it.

<CodeFix before={dafnyBefore} after={dafnyAfter} title="src/ids.ts" />

See how this is diagnosed with [Dafny](/tools/dafny).
