A service receives an `order.confirmed` webhook and charges the card. The sender retries when it does not hear back
in time, so the same order can arrive twice. Two workers take the two deliveries at the same time, both read
`unpaid`, and both charge the card. A test that runs the retry after the first delivery passes.
