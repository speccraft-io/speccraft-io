---
title: Connection leak in a fan-out
description: A report runs two queries at once; a failed query never gives its connection back, and the next report waits forever.
---

A report runs two queries at once, each with a connection from a pool of two. A connection goes back to the pool only
when its query succeeds. When a query throws, its connection is gone. A report needs two connections, so after one
failure the next report never starts, and nothing reports an error. The happy-path test passes.
