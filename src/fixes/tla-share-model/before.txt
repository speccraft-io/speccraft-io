---- MODULE UserCache ----
\* Two requests ask a cache for the same user at once. On a miss,
\* get() loads the user from the database and keeps it.
EXTENDS Naturals

Callers == {"a", "b"}

VARIABLES cached, loads, pc

vars == <<cached, loads, pc>>

Init ==
    /\ cached = FALSE
    /\ loads = 0
    /\ pc = [c \in Callers |-> "idle"]

\* get() starts: a hit returns at once, a miss awaits loadUser().
Ask(c) ==
    /\ pc[c] = "idle"
    /\ IF cached
         THEN /\ pc' = [pc EXCEPT ![c] = "done"]
              /\ UNCHANGED loads
         ELSE /\ pc' = [pc EXCEPT ![c] = "loading"]
              /\ loads' = loads + 1
    /\ UNCHANGED cached

\* loadUser() returns, and get() keeps the user.
LoadOk(c) ==
    /\ pc[c] = "loading"
    /\ cached' = TRUE
    /\ loads' = loads - 1
    /\ pc' = [pc EXCEPT ![c] = "done"]

\* loadUser() throws (a timeout, a dropped connection). get() rethrows.
LoadFails(c) ==
    /\ pc[c] = "loading"
    /\ loads' = loads - 1
    /\ pc' = [pc EXCEPT ![c] = "failed"]
    /\ UNCHANGED cached

\* The request got an error, and the client asks again.
Retry(c) ==
    /\ pc[c] = "failed"
    /\ pc' = [pc EXCEPT ![c] = "idle"]
    /\ UNCHANGED <<cached, loads>>

Next == \E c \in Callers : Ask(c) \/ LoadOk(c) \/ LoadFails(c) \/ Retry(c)

\* Requests arrive and clients retry. A load may fail, but not every time.
Spec ==
    /\ Init /\ [][Next]_vars
    /\ \A c \in Callers : WF_vars(Ask(c)) /\ WF_vars(Retry(c)) /\ SF_vars(LoadOk(c))

\* At most one database load for the user at a time.
OneLoad == loads <= 1

\* Every request gets the user in the end.
EveryoneGetsIt == \A c \in Callers : <>(pc[c] = "done")
====
