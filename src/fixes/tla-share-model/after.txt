---- MODULE UserCache ----
\* Two requests ask a cache for the same user at once. On a miss,
\* get() loads the user from the database and keeps it.
EXTENDS Naturals

Callers == {"a", "b"}

VARIABLES cached, entry, loads, pc

vars == <<cached, entry, loads, pc>>

Init ==
    /\ cached = FALSE
    /\ entry = "none"
    /\ loads = 0
    /\ pc = [c \in Callers |-> "idle"]

\* get() starts: a hit returns at once. On a miss, it awaits the load in the map,
\* or starts one and puts it there.
Ask(c) ==
    /\ pc[c] = "idle"
    /\ CASE cached ->
              /\ pc' = [pc EXCEPT ![c] = "done"]
              /\ UNCHANGED <<entry, loads>>
         [] entry = "none" ->
              /\ pc' = [pc EXCEPT ![c] = "waiting"]
              /\ entry' = "pending"
              /\ loads' = loads + 1
         [] entry = "pending" ->
              /\ pc' = [pc EXCEPT ![c] = "waiting"]
              /\ UNCHANGED <<entry, loads>>
         [] entry = "rejected" ->
              /\ pc' = [pc EXCEPT ![c] = "failed"]
              /\ UNCHANGED <<entry, loads>>
    /\ UNCHANGED cached

\* loadUser() returns: keep the user, remove the entry, every waiting request gets it.
LoadOk ==
    /\ entry = "pending"
    /\ cached' = TRUE
    /\ entry' = "none"
    /\ loads' = loads - 1
    /\ pc' = [c \in Callers |-> IF pc[c] = "waiting" THEN "done" ELSE pc[c]]

\* loadUser() throws: every waiting request gets the error.
LoadFails ==
    /\ entry = "pending"
    /\ entry' = "rejected"
    /\ loads' = loads - 1
    /\ pc' = [c \in Callers |-> IF pc[c] = "waiting" THEN "failed" ELSE pc[c]]
    /\ UNCHANGED cached

\* The request got an error, and the client asks again.
Retry(c) ==
    /\ pc[c] = "failed"
    /\ pc' = [pc EXCEPT ![c] = "idle"]
    /\ UNCHANGED <<cached, entry, loads>>

Next == LoadOk \/ LoadFails \/ \E c \in Callers : Ask(c) \/ Retry(c)

\* Requests arrive and clients retry. A load may fail, but not every time.
Spec ==
    /\ Init /\ [][Next]_vars
    /\ SF_vars(LoadOk)
    /\ \A c \in Callers : WF_vars(Ask(c)) /\ WF_vars(Retry(c))

\* At most one database load for the user at a time.
OneLoad == loads <= 1

\* Every request gets the user in the end.
EveryoneGetsIt == \A c \in Callers : <>(pc[c] = "done")
====
